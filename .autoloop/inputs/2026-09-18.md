## 公开来源候选

### 来源 1

- 标题：prefers-reduced-motion
- URL：https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion
- 访问日期：2026-09-18
- 看到的机制/设计：MDN 说明 `prefers-reduced-motion` 用来检测用户是否在系统里要求减少非必要的动态效果；页面应移除、降低或替换可能造成不适的缩放、平移等运动。
- 与铁匠铺场景的关系：铁匠铺的火苗、热点、气泡、相机飞行和 NPC 待机都在持续动。它们有氛围价值，但不是理解老杨和 iLoop 的必要条件，可以给需要安静阅读的人降下来。

### 来源 2

- 标题：Understanding SC 2.2.2: Pause, Stop, Hide
- URL：https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide
- 访问日期：2026-09-18
- 看到的机制/设计：WCAG 对自动开始、持续超过 5 秒且与其他内容并行出现的移动、闪烁、滚动信息，要求提供暂停、停止或隐藏机制，除非这类运动是活动本身必需。
- 与铁匠铺场景的关系：火光闪烁和人物 idle 是持续超过 5 秒的自动氛围，不是巡铺内容本身。适合做一个用户可见的“稳火”控制，让访客在保留场景的同时暂停主要非必要动效。

### 来源 3

- 标题：Technique C39: Using the CSS prefers-reduced-motion query to prevent motion
- URL：https://www.w3.org/WAI/WCAG22/Techniques/css/C39.html
- 访问日期：2026-09-18
- 看到的机制/设计：W3C 技术 C39 把 `prefers-reduced-motion` 作为阻止或弱化动画的可测试做法，尤其针对页面滚动或界面动效引发的分心和不适。
- 与铁匠铺场景的关系：本仓既有 CSS 过渡也有 WebGL 动画。只写 CSS media query 不够，需要同时把 JS 渲染循环里的火焰、NPC 和相机动画纳入同一个稳火状态。

## 消化与选择

今天吸收的原则：

- 自动持续动效需要尊重访客的系统偏好，也需要页面里有一个明确可切换的控制。
- 减少动态不是把 3D 场景关掉，而是保留空间、点击、导览和阅读，同时收敛非必要的闪烁、晃动、飞行和弹跳。
- 对铁匠铺来说，“稳火”比“无动画模式”更贴合语境：火还在，铺子还开，只是火候稳住，方便慢读。

我拒绝把页面改成静态截图或隐藏 3D，因为这会破坏独立 3D 互动页的本质。也拒绝只加一个 CSS media query，因为火焰和 NPC 的主要运动在 JS 渲染循环里。今天转译成“稳火阅读模式”：页面自动读取系统减少动态偏好，同时给右上角一个可见按钮，让访客随时把持续动效收住。

## 创意方案竞争

### 方案 A：稳火阅读模式

- 新颖度：4/5。它不是继续增加路线内容，而是把可访问性做成铁匠铺自己的“火候控制”。
- 访客价值：5/5。对怕晃、想慢读、移动端停留更久的访客直接有用，且不影响继续巡铺。
- 场景贴合度：5/5。“稳火”是铁匠铺语言，表达的是把炉火从热闹切到可控。
- 视觉影响：3/5。默认多一个稳火按钮，开启后动效明显收敛；静态截图变化不大，但交互和运行证据可验证。
- 实现风险：3/5。要碰渲染循环、相机补间和 NPC 动作速度，属于中高风险区域；但只加状态门控，不改模型加载和相机默认参数。

### 方案 B：火候节律条

- 新颖度：3/5。把火焰强弱和场景模式做成可见节律条，能让访客理解当前氛围状态。
- 访客价值：3/5。信息更清楚，但主要是解释已有状态，对阅读舒适度帮助有限。
- 场景贴合度：4/5。火候读数很贴合铁匠铺，但容易变成又一个 UI 指示器。
- 视觉影响：4/5。截图会更容易看到变化，但可能让底栏和右上角更拥挤。
- 实现风险：2/5。主要是 DOM 与 CSS，风险低。

### 方案 C：静看一锤导览

- 新颖度：4/5。进入每站时先给一个短暂安静定格，让访客读完站点再恢复动效。
- 访客价值：4/5。能改善内容理解，但它替用户决定节奏，可能打断“3D 页面可逛”的手感。
- 场景贴合度：4/5。像锤落后定一下火候，隐喻成立。
- 视觉影响：3/5。站点切换时有感，但默认首屏不明显。
- 实现风险：4/5。需要管理站点切换、定时恢复和用户手动控制之间的优先级，状态复杂度偏高。

## 选择与完整体验

- 最终选择：方案 A，稳火阅读模式。
- 访客会看到什么：右上角出现“稳火”按钮；如果系统开启减少动态，页面自动进入稳火状态，按钮显示“稳火开”。
- 访客能做什么：点击稳火按钮切换安静阅读；继续拖拽、缩放、点击四站、读牌、物证和火炉。
- 访客得到什么：保留铁匠铺 3D 氛围和交互，但持续火焰闪烁、NPC 摆动、相机飞行和界面弹跳收敛，阅读巡铺内容更稳。
