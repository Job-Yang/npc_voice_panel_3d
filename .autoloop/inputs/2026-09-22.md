### 来源 2

- 标题：How to Write a Museum Exhibit Script
- URL：https://www.uplandexhibits.com/museum-design-guides/exhibit-scripts/

### 来源 3

## 消化与选择

今天吸收的原则：

- 默认层只放当前任务必须的信息：你在哪一站、这一站是什么、下一锤怎么做。
- 深度信息不是删除，而是收成一个有明确名字的层，让愿意读的人主动打开。
- 3D 展示页的 UI 应把画面让给场景主体；文字导览要像展陈标签一样分层，而不是把所有证据平铺在首屏。
- 收纳之后仍要保证按钮尺寸、键盘焦点和移动端不溢出。

我拒绝继续新增第三套空间提示，因为昨天刚做了炉前路绳；也拒绝把底部信息全部删除，因为前几轮积累的进度、接力和炉印对完整巡铺仍有价值。转译成铁匠铺语言，就是“轻读炉牌”：默认只露出当前锤和可执行动作，火候、接力、炉印和收获袋都进一块可展开炉牌。

## 创意方案竞争

### 方案 A：轻读炉牌

- 新颖度：4/5。它不是再加新内容，而是把已经成形的巡铺系统重新分层，让默认体验从信息面板回到展陈空间。
- 访客价值：5/5。首次访客 5 秒内能更快看到 3D 主体、当前站和主动作；需要深入时仍能打开炉牌查看进度、接力、炉印和收获袋。
- 场景贴合度：5/5。炉牌像铁匠铺里的工序牌，承接“锤后炉印”和“收获袋”，不改变独立铁匠铺定位。
- 视觉影响：4/5。默认底栏高度会明显下降，遮挡更少，首屏场景露出更多；展开后仍保留完整信息。
- 实现风险：2/5。主要是 DOM/CSS 状态收纳和 aria 同步，不碰 GLB、相机、音频或渲染循环。

### 方案 B：焦点锤痕导航

- 新颖度：4/5。把键盘焦点和空间热点做成更明显的“锤痕”高亮，让无鼠标访客也能看清当前可操作点。
- 访客价值：4/5。可访问性更直接，键盘和低精度输入会受益；但普通鼠标访客默认视觉变化有限。
- 场景贴合度：4/5。锤痕高亮符合铁匠铺语言，但容易和昨天的路绳、热点状态重叠。
- 视觉影响：2/5。只在 hover/focus 时明显，默认截图变化不大。
- 实现风险：2/5。改 CSS 和少量焦点逻辑即可，但要逐个控件检查不遮挡。

### 方案 C：炉前静默导览

- 新颖度：3/5。默认关闭自动气泡和部分持续提示，只在点击站点后出现更清晰的对话。
- 访客价值：3/5。慢读时更安静，但已有“稳火阅读模式”覆盖了一部分需求。
- 场景贴合度：4/5。铁匠铺可以更沉稳，但这轮和 09-18 的主题容易重复。
- 视觉影响：3/5。界面更安静，但默认截图未必能稳定呈现差异。
- 实现风险：3/5。需要小心自动对白、dialog 和 NPC 气泡时序，容易影响已有互动反馈。

## 选择与完整体验

- 最终选择：方案 A，轻读炉牌。
- 访客会看到什么：默认底部巡铺栏更矮，只保留当前站、站点短句、本站主动作、读牌入口和四站按钮；3D 铁匠铺主体露出更多。
- 访客能做什么：继续按四站走、点击空间热点、敲本站动作；需要深入时打开“炉牌”，查看接力、进度、锤后炉印、收获袋和四站回执。
- 访客得到什么：第一次进门更容易先看铺子和当前锤，不被一堆状态文字压住；愿意深读时，前几轮积累的巡铺证据仍完整可达。
