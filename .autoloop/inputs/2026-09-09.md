## 公开来源候选

### 来源 1

- 标题：5. Exhibition basics
- URL：https://museumsvictoria.com.au/learning/small-object-big-story/5-exhibition-basics/
- 访问日期：2026-09-09
- 看到的机制/设计：Museum Victoria 的展览基础材料把展览文字分成主题说明、扩展标签和物件标签。物件标签不是把整段故事塞给观众，而是在靠近展品的位置说明“这是什么、为什么值得看”。本轮抓取页面时遇到 Cloudflare 挑战页，因此只使用公开搜索结果摘要作为可追溯输入，不复制正文。
- 与铁匠铺场景的关系：当前铁匠铺已经有底部四站导览和物证短读，但“当前站对应场景里的哪个人或炉”主要靠相机移动和用户猜测。可以借展签原则，把当前站的轻量标注贴近场景目标，让访客知道正在看的站点落在 3D 空间里的哪里。

### 来源 3

- 标题：HTML Overlays and Labels in Three.js
- URL：https://www.ramijames.com/learn-threejs/interaction/html-overlays-and-labels

- 看到的机制/设计：文章说明 Three.js 的标注可以用 CSS2DRenderer，也可以用 `Vector3.project()` 手动把世界坐标投影到屏幕坐标。HTML 标签适合做可样式化、可被屏幕阅读器感知的 UI 层，并可设置 `pointer-events: none` 避免遮挡 canvas 交互。
- 与铁匠铺场景的关系：本页是零构建单文件，不适合引入更多复杂渲染层。用已有 Three.js 向量投影，把当前站标签跟随 NPC 或火炉的包围盒顶部，是更轻的实现；标签只作为定位，不替代现有点击交互。

## 消化与选择

今天可借用的原则：

- 好的展签靠近对象，先解决“我正在看什么”，再补充故事。
- 寻路不是按钮列表，而是 UI、空间地标和确认反馈一起工作。
- 3D 页面中的说明文字不一定要做成模型；轻量 HTML overlay 可以跟随 3D 坐标，并保持可读和可维护。

我拒绝把页面改成小地图、任务雷达或游戏式箭头。铁匠铺仍然是独立 3D 展示页，不需要“导航系统”盖过铺子本身。今天只给当前站加一枚“炉钉定位”：切到老杨、iLoop、近况或火炉时，场景对应位置出现小标签，告诉访客“这一站就在这里”。

## 创意方案竞争

### 方案 A：当前站炉钉定位

- 新颖度：4/5。前几轮做了路线、进度、物证和完成回执，但还没有把当前站明确钉回 3D 空间。
- 访客价值：5/5。首次访客能立即知道底部当前站对应哪个人物或火炉，减少“按钮在底部、目标在场景里”的断裂。
- 场景贴合度：5/5。炉钉、站位和火候入口都是铁匠铺语言；它标注的是既有人物和火炉，不新增不相关内容。
- 视觉影响：3/5。默认画面会多一个小型空间标签，切站时位置和文字变化明显，但不会遮挡主体。
- 实现风险：3/5。需要把 3D 包围盒投影到屏幕坐标，并处理移动端遮挡和窗口 resize；不碰模型加载和渲染核心。

### 方案 B：铺内小地图

- 新颖度：3/5。小地图能直接表达四站布局，但网页和游戏里都常见。
- 访客价值：4/5。访客能看到四站相对位置，适合快速跳转。
- 场景贴合度：3/5。可以包装成“炉前平面图”，但仍更像工具 UI，容易把独立展示页推成导航产品。
- 视觉影响：4/5。默认首屏会多一块固定面板，信息很明显。
- 实现风险：4/5。需要维护场景缩略位置、点击命中、移动端布局和与底部 rail 的关系，且和已有导览重复。

### 方案 C：抵达时相机点头和光圈

- 新颖度：4/5。切站时相机轻微点头、目标脚下短暂亮起，可以更有现场感。
- 访客价值：3/5。反馈更有动势，但如果访客连续切站，动画可能打断阅读。
- 场景贴合度：4/5。炉光和站位反馈贴合铁匠铺，但脚下光圈偏通用游戏 UI。
- 视觉影响：4/5。动效明显，5 秒内能看出变化。
- 实现风险：4/5。会碰相机、光源和动画节奏；若处理不好，容易造成眩晕或和现有 `focusOn()` 抢控制。

## 选择与完整体验

- 最终选择：方案 A，当前站炉钉定位。
- 访客会看到什么：首屏仍是铁匠铺、三位 NPC、火炉和底部四站路线；当前站上方多一枚小标签，显示“第几站、站名、短定位”。切换站点时，标签跟到对应 NPC 或火炉上方。
- 访客能做什么：继续用底部路线、NPC、火炉和键盘左右切站；每次切站都能借场景标签确认自己正在看谁或哪里。
- 访客得到什么：四站导览不再只是一条底部 UI，而是和铺内空间建立对应关系；首次访客更容易把“老杨、iLoop、近况、火炉”记成场景里的四个位置。
