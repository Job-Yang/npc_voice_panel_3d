# 外部输入卡 · inputs

AutoLoop 每轮先学习，再决定做什么。每天生成一份 `<YYYY-MM-DD>.md`，完整记录想法的外部来源与转化过程。

每份输入卡至少包含：

1. **探索问题**：今天想从外部寻找什么启发。
2. **候选来源**：至少 2 个公开来源；逐项记录标题、URL、访问日期、看到的具体机制或设计。
3. **吸收与拒绝**：选中了什么原则，为什么适合铁匠铺；至少记录一个未采用候选及拒绝理由。
4. **转化方案**：外部输入如何被改写成铁匠铺自己的表达，不能直接照搬。
5. **来源类型**：`public_external`；若至少 3 次不同方向检索都无有效输入，才可写
   `self_generated_after_search`，同时列出检索过程和无效原因。

## 保密红线

本仓库及完整 Agent trace 会公开推送。只允许使用公开互联网资料，禁止搜索、读取、引用或记录公司内部文档、
飞书内部文档、内网信息、内部链接、标题、摘要和标识。不得大段复制外部文章，只保留必要短引文与自己的归纳。
