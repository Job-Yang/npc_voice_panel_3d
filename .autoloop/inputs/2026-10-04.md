# 2026-10-04 外部输入卡

## 公开来源候选

### 来源 1

- 标题：Target Size (Minimum) (Level AA)
- URL：https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum
- 访问日期：2026-10-04
- 看到的机制/设计：WCAG 2.2 的目标尺寸最小要求强调，指针输入目标至少应达到 24 x 24 CSS 像素，或者在目标较小时保证相邻目标之间有足够间距，避免误触。
- 与铁匠铺场景的关系：铁匠铺右上角已有稳火、模式、音乐三枚小按钮，左上还有控制面板。桌面上成立，但在窄屏手机上容易贴得太近甚至挤压。这个来源提醒我，本轮可以把“能点准、不会互相压住”作为可验证改善。

### 来源 2

- 标题：Accessible responsive design
- URL：https://web.developers.google.cn/articles/accessible-responsive-design
- 访问日期：2026-10-04
- 看到的机制/设计：web.dev 强调响应式设计不只是换列数，还要照顾不同输入方式；触屏设备上的可点击目标要足够大，布局也要能适配未来和当前各种屏幕宽度。
- 与铁匠铺场景的关系：铁匠铺现在的主体验是拖拽 3D 场景和点击按钮。移动端首屏顶部同时承担标题、面板、稳火、模式、音乐和炉声状态，若控件拥挤，会直接影响访客开始巡铺前的第一下操作。

### 来源 3

- 标题：Material Design 3 · Designing structure
- URL：https://m3.material.io/foundations/designing/structure
- 访问日期：2026-10-04
- 看到的机制/设计：Material Design 建议常见平台的触控目标至少 48 x 48 dp，即使视觉图标较小，也应通过内边距提供稳定点击区域。
- 与铁匠铺场景的关系：铁匠铺不是 Material 风格，但“视觉紧凑、触控面积足够”的原则可转译为移动端炉台：按钮视觉仍克制，点击范围和行距更稳定，炉声状态不压在按钮下面。

## 消化与选择

今天吸收的原则：

- 移动端不是把桌面按钮整体缩小，而是把操作分层，让每个动作有稳定触控面积。
- 可访问性改善也可以是完整主题；如果首屏控制不会互相遮挡，访客更容易进入四站导览。
- 响应式布局要维持视觉顺序。标题、常用控制、状态提示和底部巡铺要各自占住清楚区域。
- 本轮不应该新增 3D 模型或继续加叙事文字，因为最近几轮已经补了路线、炉牌、聚焦光和炉声状态；今天更适合修入口质量。

我拒绝把移动端改成复杂抽屉或隐藏所有控制，因为铁匠铺的按钮本来就少，隐藏会让声音、稳火和模式变得更难发现。也不做大范围重排底部导览，避免把已验证的四站巡铺重新打散。

## 创意方案竞争

### 方案 A：掌中炉台分层

- 新颖度：3/5。不是炫技新功能，而是把移动端首屏控制从拥挤按钮排成两层炉台。
- 访客价值：5/5。手机访客能更容易点中控制面板、稳火、模式和音乐，也能读到炉声状态。
- 场景贴合度：4/5。像把炉前工具按手边顺序摆开，不改变铁匠铺叙事。
- 视觉影响：3/5。桌面几乎不变，手机首屏顶部更清楚；改善不靠新增物件，而靠减少遮挡。
- 实现风险：2/5。主要改移动端 CSS 和调试取证，不碰模型、相机、音频时序和渲染循环。

### 方案 B：完巡后的复访炉票

- 新颖度：4/5。四站走完后给访客一个“下次进铺先看哪里”的复访提示。
- 访客价值：4/5。能强化离铺后的记忆点和复访路径。
- 场景贴合度：5/5。炉票语境贴合铁匠铺，也承接已有离铺炉票。
- 视觉影响：2/5。只有完成四站后才出现，默认首屏不明显。
- 实现风险：3/5。要继续扩展已经较密的炉牌文案，容易让底部信息层重新变重。

### 方案 C：键盘巡铺补全

- 新颖度：3/5。给 Escape、Home、数字键等补上更完整的键盘巡铺。
- 访客价值：4/5。对键盘用户有帮助，也利于无鼠标浏览。
- 场景贴合度：3/5。工程质量强，但铁匠铺现场感较弱。
- 视觉影响：1/5。默认画面几乎不变，需要专项验证才能感知。
- 实现风险：3/5。全局键盘事件要避开彩蛋输入、表单和对话按钮，容易引入意外触发。

## 选择与完整体验

- 最终选择：方案 A，掌中炉台分层。
- 访客会看到什么：桌面保持原样；手机上顶部标题下方的控制不再挤成一排，控制面板、舒缓/火炉、音乐在第一层，稳火和炉声状态在第二层。
- 访客能做什么：在窄屏上也能稳定点开控制面板、切换稳火、切换场景模式、打开或关闭音乐，并继续使用底部四站巡铺。
- 访客得到什么：第一屏更像可操作的掌中炉台，少了按钮贴边和重叠风险；声音状态仍可读，3D 主体和底部巡铺没有被新增内容压住。
