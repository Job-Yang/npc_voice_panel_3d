# 2026-09-04 外部输入卡

## 候选来源

### 来源 1：How to Improve Museum Wayfinding

- URL: https://www.stqry.com/blog/how-to-improve-museum-wayfinding
- 访问日期：2026-09-04
- 看到的机制/设计：博物馆导览不只靠标牌，而是把决策点、命名一致性、可见但不抢展品的提示、建筑和故事线索结合起来。文章强调自助导览让访客按自己的节奏移动，同时在合适位置收到相关内容。
- 与铁匠铺场景的关系：当前铁匠铺已有底部四站巡铺路线，但路线更像按钮列表。它需要在每个站点给一条“你现在看什么”的短提示，让访客不用猜当前站和场景内容的关系。

### 来源 2：Interactive Way-finding Maps - Culture Connect Case Study

- URL: https://www.axiell.com/solutions/product/cultureconnect/interactive-way-finding-maps-culture-connect-case-study/
- 访问日期：2026-09-04
- 看到的机制/设计：互动导览图通过可点击兴趣点把展区和路线串起来。重点不是堆满文字，而是让每个点位有清楚位置、标题和继续探索入口。
- 与铁匠铺场景的关系：老杨铁匠铺不是大博物馆，但同样有四个点位：老杨、iLoop、近况、火炉。今天可借鉴“点位 + 当前说明”的结构，把底部路线升级成可读的当前位置提示。

### 来源 3：Understanding Success Criterion 2.4.13: Focus Appearance

- URL: https://www.w3.org/WAI/WCAG22/Understanding/focus-appearance.html
- 访问日期：2026-09-04
- 看到的机制/设计：W3C 对焦点外观的解释强调，键盘用户需要明确看见当前焦点落在哪里；焦点状态应有足够可见的视觉变化。
- 与铁匠铺场景的关系：巡铺路线本身已经是按钮，但键盘切站时焦点不够醒目。给路线按钮、对话按钮和滑杆补清晰的 `focus-visible`，能让不靠鼠标的访客也顺着四站逛铺。

## 消化与选择

三个来源共同指向一个原则：导览不是多加说明书，而是在访客做选择的位置给足方向感。当前页面的内容已经比 8 月底更清楚，昨天又把 iLoop 五锤做成可点层级；今天不该继续往 iLoop 里塞内容，而应该让“四站巡铺”本身更像一个可信的自助导览。

我拒绝做新的 3D 路标或地面箭头，因为这容易回到“靠新增可见物件证明迭代”的老路，也可能触碰不要手搓最终 3D 模型的约定。今天把外部输入转译为“巡铺当前站提示”：底部路线增加一条随站点变化的短句，告诉访客当前站是什么、为什么看它；同时补键盘左右键切站和可见焦点，让导览既服务鼠标也服务键盘。

## 创意方案竞争

### 方案 A：巡铺当前站提示

- 新颖度：3/5。不是大视觉奇观，但把已有巡铺路线从四个按钮升级成自助导览条，信息组织更像展览导览。
- 访客价值：5/5。首次访客不用点开每个对话才知道四站含义，能在底部看到当前位置、站名和一句空间化摘要。
- 场景贴合度：5/5。铁匠铺本来就是“进门逛铺”，当前站提示像铺内小导览牌，仍然服务老杨、iLoop、近况、火炉四个锚点。
- 视觉影响：3/5。默认首屏会多一条克制提示，5 秒内能看见；不会新增模型或遮挡炉火主体。
- 实现风险：2/5。主要改 UI 样式和导航状态，不碰模型加载、相机算法、渲染循环或音频时序。

### 方案 B：键盘巡铺模式

- 新颖度：4/5。把左右方向键、Enter 和 Escape 组织成完整键盘导览，会让页面更可访问。
- 访客价值：4/5。键盘用户收益明显，但鼠标访客的首屏理解提升有限。
- 场景贴合度：3/5。它是交互质量提升，和铁匠铺叙事间接相关。
- 视觉影响：2/5。主要是焦点状态和操作行为，截图变化有限。
- 实现风险：3/5。要处理焦点、对话关闭和已有输入彩蛋，容易和隐藏指令监听产生边界问题。

### 方案 C：炉光引导四站

- 新颖度：4/5。点击四站时用灯光强弱或人物头顶光形成视觉指向，像铺内光线带路。
- 访客价值：4/5。访客能更直观看到当前关注对象。
- 场景贴合度：5/5。用炉光导览非常贴合铁匠铺。
- 视觉影响：4/5。默认和切站变化都会明显。
- 实现风险：4/5。需要调灯光状态、NPC halo 和火炉模式，可能干扰已有舒缓/火炉模式和性能取舍。

## 选择与完整体验

- 最终选择：方案 A，巡铺当前站提示，并吸收方案 B 中风险最低的左右键切站和 `focus-visible`。
- 访客会看到什么：底部巡铺路线顶部出现“第几站 + 站名 + 一句摘要”，默认写明第一站老杨；点击 iLoop、近况或火炉时，这条提示同步切换。
- 访客能做什么：访客可以用鼠标点击四站，也可以在路线按钮上用左右方向键切换站点；键盘焦点会有清晰描边。
- 访客得到什么：不需要摸索就知道每一站为什么存在，首次逛铺的方向感更强，同时移动端和桌面端都不遮挡核心场景。

未选方案 B 的原因：纯键盘巡铺很有价值，但如果只做键盘逻辑，对普通访客的可感知变化较弱。今天把其中最稳的左右键和焦点状态纳入方案 A。未选方案 C 的原因：炉光引导更戏剧化，但会触碰灯光模式和火炉模式，当前不值得为一个导览主题冒较高风险。
