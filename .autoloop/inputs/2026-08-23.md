# 2026-08-23 外部输入卡

访问日期：2026-08-23

## 公开来源

1. `Interactive 3D Web Resume`
   URL: https://yeoul.world/projects/interactive-3d-resume

   看到的机制：这个项目把个人经历和项目节点做成可探索的空间系统，作品、里程碑和身份不是普通列表，而是变成有位置、有关系的 3D 节点。它强调 3D 个人主页可以用空间组织信息，让访客通过移动视线理解“这个人做过什么”。

   与铁匠铺的关系：老杨的铺子已经有火、入口、工序和环境，但“锻过哪些成品”仍主要藏在对话文案里。可以把项目成果做成墙上的样品，而不是继续把项目写进普通按钮。

2. `Workshop & Forge Design`
   URL: https://civilizationrebuild.com/phase-3-small-group/settlement-planning/workshop-forge-design

   看到的机制：文章描述铁匠铺工作流常按 Forge -> Anvil -> Slack tub -> Finishing area 组织，强调炉、砧、淬火和收尾区之间应该自然流动，减少来回折返。它提醒我真实工作空间会把“成品、收尾、检查”放在火和砧之后。

   与铁匠铺的关系：本仓过去几轮已经补了风箱、火印、闭环锻造台和排烟罩，讲的是开工、控火、验证和交付动作。今天可以补“收尾后的陈列区”：让访客看到老杨已经锻出来的工具样品，补上个人主页的项目识别。

3. `How Exhibition Signage Enhances the Visitor Experience`
   URL: https://museumsandheritage.com/advisor/posts/how-exhibition-signage-enhances-the-visitor-experience/

   看到的机制：文章把展览标识分成解释标签、导视和叙事辅助，重点是让一组物件从“散落的展品”变成“有意义的体验”。短标签能先引发兴趣，更多内容再按需展开。

   与铁匠铺的关系：老杨铁匠铺的物件越来越多，访客需要在默认视角快速读出“这些东西和老杨有什么关系”。样品墙可以用短名牌和颜色分层，把 iLoop、LinkMap、包体积治理这些项目变成一眼能扫到的作品样本。

## 消化与选择

这些来源共同给出的原则是：个人主页里的项目不必总是文案列表，可以转成空间节点；真实工作间需要有从开工到收尾的流线；解释标签应该先给短而明确的钩子，再把细节留给点击。对老杨的铁匠铺来说，今天最缺的不是又一个“怎么开工”的物件，而是“已经锻成了什么”的可见证据。

我拒绝把页面改成多场景作品集、滚动章节或大型项目墙，因为本仓仍是单屏 3D 欢迎页。今天的转译是“成品样品墙 · 已锻成果”：在默认视角右后方新增一面挂满样品的铁木展示墙，三件发光样品分别代表 iLoop、LinkMap 和包体积守门；点击后样品灯逐个亮起，文案说明这里摆的不是奖杯，而是可回炉、可验收、可继续打磨的工具。

## 创意方案竞争

### 方案 A

主题：成品样品墙 · 已锻成果。

新颖度：4/5。它不再继续补开炉动作，而是补“作品结果”这一层，把个人主页的项目识别从对话里拿到默认画面中。

访客价值：5/5。访客无需先点击 NPC，就能看到老杨实际锻过的方向；点击后还能把 iLoop、LinkMap 和包体积治理理解成一组可交付样品。

场景贴合度：5/5。铁匠铺挂样品、工具和铭牌很自然，也接在炉、砧、火印之后，形成从锻造到陈列的闭环。

视觉影响：4/5。默认视角右后方会多出竖向展示墙、三件发光样品和短铭牌，5 秒内能看出新增了“成果陈列”。

实现风险：3/5。风险主要是右侧已有 YQ 工作台、匠印台和委托托盘，样品墙如果太大可能拥挤；但用窄墙面、贴墙位置和轻动画可以控制。

### 方案 B

主题：淬火记录槽 · 冷却复盘。

新颖度：3/5。淬火和复盘隐喻成立，但和已有水桶、火印台、排烟罩一样仍是单个工序设备。

访客价值：4/5。它能解释“做完要冷却复核”，对 iLoop 的验证收口有帮助；但默认第一眼可能只看到又多了一个容器。

场景贴合度：5/5。淬火槽是铁匠铺核心设备，和收尾流程高度贴合。

视觉影响：3/5。地面层已经很满，新槽容易被风箱、托盘、火印台遮住，默认视角变化不如样品墙明确。

实现风险：2/5。几何和水面动画简单，风险较低；但也容易变成低风险小修补。

### 方案 C

主题：炉边访客路线灯 · 三步看铺。

新颖度：4/5。用地面小灯串联“认识老杨、看 iLoop、找协作”能改善首次浏览路径，不只是新增一个物件。

访客价值：4/5。它能减少访客面对多物件时的迷路感，并强化欢迎页导览。

场景贴合度：4/5。炉边灯、地面火点和脚下路线适合铺子，但和 2026-08-21 的门槛火点有些接近。

视觉影响：4/5。默认视角能看到一条亮线，但如果太亮会像 UI 指引而不是铁匠铺物件。

实现风险：3/5。需要处理多个热区和视觉层级，不能让路线灯抢掉所有物件注意力。

## 选择与完整体验

最终选择：方案 A，成品样品墙 · 已锻成果。

选择理由：今天不选风险最低的淬火槽，也不选偏导览优化的路线灯，是因为最近几轮已经充分讲了“如何开炉和如何闭环”，但个人主页还缺少“我已经做过什么”的一眼证据。样品墙在视觉上足够明显，也能把老杨的 iOS 工程、iLoop 和治理工具以铁匠铺语言陈列出来，补齐欢迎页的主人身份。

访客会看到什么：默认视角右后方多出一面铁木样品墙，上面挂着三个发光样品：闭环环扣、链路刀胚、包体积秤锤，每个样品下面有短铭牌和验收刻痕。

访客能做什么：悬停能看到“成品样品墙 · 已锻成果”，点击后火炉模式启动，三件样品依次亮起，墙上的验收点和火星短暂增强，并弹出解释这些样品如何代表老杨锻过的工具。

访客得到什么：在欢迎页第一眼就能理解这家铺子不是只有氛围，它有具体作品方向；点击后能把老杨的 iLoop、LinkMap、包体积治理和“可验证交付”联系起来。
