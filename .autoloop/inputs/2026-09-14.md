# 2026-09-14 外部输入卡

## 公开来源候选

### 来源 1

- 标题：Progressive Disclosure in UX Design
- URL：https://supercharge.design/articles/progressive-disclosure-in-ux-design
- 访问日期：2026-09-14
- 看到的机制/设计：文章强调渐进披露通过减少同屏可见复杂度来降低误点、漏看和放弃的概率；先给用户最必要的信息，再让他们按需展开更深层内容。
- 与铁匠铺场景的关系：铁匠铺底部导览已经连续几轮加了站点、问题、带走结论、行动、进度、物证和炉印。信息都重要，但默认全摊开会压住 3D 铺子本身。今天可以把深层读牌收进“读牌”按钮，让首屏先看铺子和当前行动。

### 来源 2

- 标题：Exhibition Labelling
- URL：https://mgnsw.org.au/sector/resources/online-resources/exhibition/exhibition-labelling/
- 访问日期：2026-09-14
- 看到的机制/设计：展览标签建议建立信息层级：总体入口、主题区域、单件展品说明分层呈现；视觉符号、编号和一致的字体间距帮助访客快速理解，不需要每段说明同等重量。
- 与铁匠铺场景的关系：四站巡铺可以像小展览一样处理。站名、导览短句和行动是“入口层”，问题、带走结论和物证是“展签层”。把展签层折叠起来，能保留内容深度，同时让路线更像有层级的空间导览。

### 来源 3

- 标题：Creating Text
- URL：https://threejs.org/manual/en/creating-text.html
- 访问日期：2026-09-14
- 看到的机制/设计：three.js 手册指出 DOM + CSS 通常是添加高质量文本最简单、最快的方式，适合描述性 overlay；复杂文字不必都进入 3D 几何。
- 与铁匠铺场景的关系：本轮不需要新 3D 模型，也不应该把每条说明做成空间物件。用既有 HTML 导览层重整文本层级，符合铁匠铺“可读信息用轻量层承接”的方向。

## 消化与选择

今天吸收的原则：

- 复杂体验应先暴露最关键行动，把解释层放到用户主动展开之后。
- 展览式空间需要信息层级，入口提示、主题说明和物证解释不应同屏同权重。
- 3D 页面里的长文本适合留在 DOM overlay 中处理，不必为每个说明新增模型。

我拒绝继续新增站点、完成弹窗或空间标签。最近几轮已经把四站巡铺补得很完整，问题已经从“缺内容”变成“入口太密”。今天的转译是“巡铺读牌分层”：默认底栏只保留当前站、短导览、行动和进度；访客需要更深理解时，再展开读牌看到问题、带走结论和物证。

## 创意方案竞争

### 方案 A：巡铺读牌分层 · 首屏轻一点

- 新颖度：4/5。它不是新增内容，而是把连续几轮积累的导览信息重新分层，让已有内容从常显说明变成可控展签。
- 访客价值：5/5。首次进入时更容易先看 3D 铺子和当前行动；想深入的人仍能一键展开问题、带走和物证。
- 场景贴合度：5/5。读牌像展览标签，适合铁匠铺这种“边看空间边读工序”的导览方式。
- 视觉影响：4/5。默认底栏高度下降，画面下方更轻；展开后仍保留原来的信息深度。
- 实现风险：2/5。只改 HTML/CSS 状态和少量按钮逻辑，不碰模型、相机、灯光、BGM 或渲染循环；主要风险是移动端展开后溢出。

### 方案 B：首次进门自动短讲 · 3 秒后浮出老杨欢迎语

- 新颖度：3/5。自动欢迎能增强开场，但页面已有 NPC 气泡和随机闲聊机制，不是全新体验。
- 访客价值：3/5。能告诉访客先做什么，但自动弹层可能打断看场景，也容易和已有对话气泡竞争。
- 场景贴合度：4/5。老杨开门迎客符合铁匠铺，但自动播报不如用户主动读牌克制。
- 视觉影响：3/5。首屏会更热闹，但也可能遮挡人物和炉火。
- 实现风险：3/5。要处理首次加载时机、已有自动闲聊、音频解锁和弹层关闭逻辑。

### 方案 C：四站路线迷你地图 · 用方位图标提示站点位置

- 新颖度：4/5。把路线做成空间小地图，会让“站点在哪里”更直观。
- 访客价值：4/5。对导航有帮助，但目前已经有 3D 炉扣和 station pin，收益可能重复。
- 场景贴合度：4/5。铁匠铺平面图贴合展馆导览，但会偏向工具化，弱化沉浸感。
- 视觉影响：4/5。默认视角会新增明显 UI 元素，可能抢走 3D 主体注意力。
- 实现风险：4/5。需要适配桌面和移动端位置、点击、当前态与遮挡，且容易和现有底栏重复。

## 选择与完整体验

- 最终选择：方案 A，巡铺读牌分层 · 首屏轻一点。
- 访客会看到什么：进入页面时，底部巡铺栏只显示当前站、短导览、行动按钮、进度和四个站点按钮，默认不再同时铺开问题、带走结论和物证。
- 访客能做什么：点击“读牌”展开本站问题、带走结论和物证；再点“收起读牌”回到轻量路线，也可以继续鉴定或切换物证。
- 访客得到什么：初访时更容易把注意力放回铁匠铺 3D 场景和下一步行动；深入阅读时仍能拿到上一轮累积的完整说明，不丢内容。
