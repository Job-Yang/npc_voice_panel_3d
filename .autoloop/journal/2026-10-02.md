# 2026-10-02 自迭代手记

## 现状分析

今天开局工作区干净，`main` 与 `origin/main` 同步；本轮 run 目录里只有 supervisor 预检材料，没有今天已经写了一半的 input 或 journal。主人反馈仍然是两条硬约束：页面必须独立于个人主页；需要新 3D 模型时不能由我手搓最终模型。

最近多轮都围绕四站巡铺补信息：路签、匠印短句、离铺炉票、炉前三拍、炉边回声、昨天的落锤聚焦光已经让“去哪、读什么、记什么、看哪里”都很完整。今天再看页面，真正的问题不是缺一条新说明，而是默认底部 UI 已经偏厚。三拍很有用，但常驻时会和当前站、动作、路签、空间热点一起抢 3D 铺子的第一眼。

所以今天做减法，不新增模型，不改相机、音乐、灯光和渲染循环核心；主题是“收炉看铺”：把常驻三拍收进已有炉牌，让默认视角更轻。

## 输入如何变成想法

我吸收的是“默认少一点、需要时再展开”和“让 3D 本体重新成为主角”的原则。铁匠铺现在的路线说明已经足够，昨天还补了空间聚焦光；如果今天继续加解释，会把页面推回文字面板。

转译成铁匠铺自己的表达，就是把炉前三拍像账本一样放回炉牌：台面上只留当前要敲的一锤，访客想回看“当前、刚刚、下一步”时再展开炉牌。

## 创意方案竞争

方案 A：收炉看铺。新颖度 4/5，它从继续加法转成界面减法；访客价值 5/5，默认遮挡更少且三拍不丢；场景贴合度 5/5，像把账本放回炉牌；视觉影响 4/5，默认底栏明显更轻；实现风险 2/5，只移动现有 DOM 层级和按钮状态。

方案 B：炉牌阅读模式。新颖度 4/5，提供专门慢读状态；访客价值 4/5，深读更顺但会新增模式概念；场景贴合度 4/5，稳火慢读贴合铺子语境；视觉影响 3/5，默认态改善有限；实现风险 3/5，要协调稳火、读牌、炉牌和移动端高度。

方案 C：巡铺完成自动回铺心。新颖度 3/5，完成后自动回默认构图；访客价值 3/5，有仪式感但可能打断自由探索；场景贴合度 4/5，回炉收口贴合；视觉影响 4/5，完成后明显；实现风险 4/5，涉及相机和弹窗时序。

最终选择方案 A。它不是默认选最小改动，而是承认当前更需要减法：最近几轮已经把信息做厚，今天要让 3D 铁匠铺重新露出来。

## 今天的想法

做“收炉看铺”：默认底部巡铺栏不再常驻显示“当前、刚刚、下一步”三张小卡，只保留当前站说明、读牌/炉牌/回铺心、本站动作和四站入口；打开“炉牌”后，再看到三拍、炉脉、进度、炉印和收获袋。

访客会看到什么：默认底栏少一整行信息，场景里的人物、火炉、热点和昨天的聚焦光更突出。

访客能做什么：照常拖拽、切站、点 NPC/火炉；需要回看节奏时点“炉牌”。

访客得到什么：默认看铺更清爽，深读信息仍然可达。

## 为什么这么做

我没有选阅读模式，因为它会新增一个需要解释的状态，和现有“稳火”按钮有职责重叠。也没有选完成后自动回铺心，因为那会接管相机和弹窗，风险更高，而且完成态总结已经足够。

收炉看铺的权衡更清楚：三拍是好信息，但不是首屏每秒都必须看见的信息。把它放进炉牌后，默认态更像一个 3D 展示页，展开态仍保留回看和收束能力。
