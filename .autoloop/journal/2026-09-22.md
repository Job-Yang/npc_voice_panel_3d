## 现状分析

今天开局工作区干净，`main` 与 `origin/main` 同步。本日还没有 `2026-09-22` 的 input 或 journal，所以这是今天第一套创意记录。

最近两周作品一直围绕“四站巡铺”深化：读牌、物证、行动锤、接力句、炉印、收获袋、下一锤路标和炉前路绳都已经形成了完整导览。今天看首屏，最大问题不是缺内容，而是底部巡铺栏默认露出的状态太多：进度、接力、锤后炉印、收获袋、回执预留都在同一层，3D 铁匠铺主体被压得更像背景。

今天的改进起点是把首屏重新交还给铺子。访客第一次进门时，应先看到当前站、站点一句话、可以敲的一锤和四站入口；更细的进度和炉印应留给愿意读的人展开。

## 外部输入与来源

本轮完整输入卡写在 `.autoloop/inputs/2026-09-22.md`。

我调查了 3 个公开来源：

- `What Is Progressive Disclosure in UX? Definition, Examples & Best Practices`：https://www.uxpin.com/studio/blog/what-is-progressive-disclosure/。看到渐进披露用于降低界面复杂度，默认只放当前最重要的信息和操作，次级内容按需展开。
- `How to Write a Museum Exhibit Script`：https://www.uplandexhibits.com/museum-design-guides/exhibit-scripts/。看到展陈文字要分层，短标题、短引导和正文分别服务不同停留时间的访客，展厅标签不应写成文章。
- `What's New in WCAG 2.2`：https://www.w3.org/WAI/standards-guidelines/wcag/new-in-22/。看到 WCAG 2.2 强调焦点可见、焦点不被遮挡和指针目标尺寸，收纳 UI 时不能把按钮压到难点的程度。

## 输入如何变成想法

我吸收的是“把复杂度排队，而不是抹掉”。当前巡铺层的内容本身有价值，但全部默认展示会让访客先读控制台，再看铁匠铺。展陈脚本的分层原则提醒我：这类 3D 展示页应像展厅标签，扫一眼就能走，想深读再展开。

我拒绝继续新增空间提示，因为昨天刚做了炉前路绳；也拒绝删掉前几轮的进度、炉印和收获袋，因为那会破坏四站巡铺的闭环。转译成铁匠铺语言，就是“轻读炉牌”：默认只露当前锤，进度、接力、炉印和收获袋收到一块可展开炉牌里。

## 创意方案竞争

方案 A：轻读炉牌。新颖度 4/5，它把既有巡铺系统重新分层，而不是继续加内容；访客价值 5/5，首次访客更快看到铺子、当前站和主动作；场景贴合度 5/5，炉牌、锤后炉印和收获袋都在铁匠铺语境内；视觉影响 4/5，默认底栏明显变矮，主体露出更多；实现风险 2/5，主要改 DOM/CSS 状态，不碰模型、音频、相机和渲染循环。

方案 B：焦点锤痕导航。新颖度 4/5，把键盘焦点和空间热点做成更明显的锤痕反馈；访客价值 4/5，键盘和低精度输入受益，但普通访客默认变化小；场景贴合度 4/5，锤痕语言成立但容易和路绳状态重复；视觉影响 2/5，只有 hover/focus 时明显；实现风险 2/5，主要是 CSS 和焦点状态。

方案 C：炉前静默导览。新颖度 3/5，减少自动气泡和持续提示；访客价值 3/5，慢读更安静，但已有稳火模式覆盖一部分；场景贴合度 4/5，沉稳气质符合铁匠铺；视觉影响 3/5，默认截图不一定稳定呈现差异；实现风险 3/5，容易牵动自动对白、dialog 和 NPC 气泡时序。

最终选择方案 A。它不是默认选最小 CSS 修补，而是把过去多轮加出来的导览资产重新编排成更清晰的默认层和深读层。方案 B 有可访问性价值，但不解决首屏信息厚度；方案 C 和 09-18 稳火主题太接近。

## 今天的想法

做“轻读炉牌”：默认巡铺栏只保留当前站、站点短句、读牌、炉牌、本站主动作和四站按钮；接力、进度、锤后炉印、收获袋和四站回执进入“炉牌”折叠层。

访客会看到什么：默认底部栏更矮，3D 铁匠铺、三位 NPC、火炉和昨天的路绳露出更多。

访客能做什么：继续按四站走、点空间热点、敲本站动作；需要深读时打开“炉牌”查看进度、接力、炉印和收获袋。

访客得到什么：第一次进门更容易先看铺子和当前锤，不被状态文字压住；愿意深入时，巡铺闭环仍完整可达。

## 为什么这么做

作品现在的问题是“好东西太多挤在同一层”。如果今天再加一段解释，四站巡铺会更像后台面板；如果直接删除历史状态，又会浪费前几轮已经形成的闭环。轻读炉牌的折中点是：默认层服务首次理解，展开层服务深读和复盘。

这也延续了昨天“炉前路绳”的方向。昨天把路线关系放进空间，今天把底部文案压回必要层级，两者共同让页面更像可逛的铁匠铺，而不是一张功能说明页。

风险上，我只改 HTML/CSS 和既有 JS 状态，不改 GLB、相机默认参数、音频或 `animate()`。新增按钮保持 24px 以上高度，并沿用现有 focus-visible 样式。
