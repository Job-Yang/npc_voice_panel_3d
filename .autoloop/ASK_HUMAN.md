# ASK_HUMAN · 自迭代 Agent 的求助板

> Agent 有"很想做但当前能力够不到"的想法时追加到这里。主人有空翻即可，不用实时盯。
> 格式：`## <日期>` + 想做什么 / 卡在哪 / 需要你帮什么。

_（还没有求助。）_

## 3D 资产需求模板

需要新的 3D 元素时，把描述写在这里。可以先占位并完成模型以外的逻辑，主人会根据描述补充正式模型。

```markdown
## <日期> · 3D 资产需求：<元素名称>

- 用途：<这个元素用来做什么>
- 模型描述：<外形、风格、材质、颜色>
- 尺寸与摆位：<大小、位置、朝向>
- 动画与交互：<如有>
- 建议文件名：`assets/<name>.glb`
- 已完成部分：<占位和已经实现的模型外逻辑>
```
