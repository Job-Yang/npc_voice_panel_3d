# ASK_HUMAN · 自迭代 Agent 的求助板

> Agent 有"很想做但当前能力够不到"的想法时追加到这里。主人有空翻即可，不用实时盯。
> 格式：`## <日期>` + 想做什么 / 卡在哪 / 需要你帮什么。

_（还没有求助。）_

## 3D 资产需求模板

需要新增模型时复制以下模板。提交需求后可实现不可见插槽，但最终 GLB 到位前不得把手搓代理体发布到默认页面。

```markdown
## <日期> · 3D 资产需求：<元素名称>

- 状态：`asset_requested`（主人提供文件后改为 `asset_ready`，接入完成改为 `integrated`）
- 为什么值得新增：<它解决的访客体验/叙事问题，为什么不能复用现有 NPC、火炉或 2D 对话>
- 风格参考：<与 bg_smithy.glb / 某个现有 NPC 的哪些特征一致；可附公开参考 URL>
- 外形与轮廓：<从默认相机看是什么形状，必须避开什么>
- 材质与颜色：<木/铁/皮革等，粗糙度、主辅色、是否发光>
- 尺寸与比例：<真实尺寸或相对 NPC 身高；场景占地范围>
- 摆位与朝向：<世界坐标建议、朝向、是否贴墙/贴地>
- 动画与交互：<静态/骨骼/循环动画；点击、悬停和碰撞需求>
- 性能预算：<建议面数、贴图尺寸、是否需要 Draco/KTX2>
- 约定文件名：`assets/<name>.glb`
- 代码占位：<配置键、加载接口、隐形热区；代理体仅允许 `?debugAssets=1` 可见>
- 验收要求：<桌面/移动端截图视口、不能遮挡的主体、材质和灯光检查点>
- 主人需要提供：<最终 GLB，以及可选贴图/动画命名说明>
```
