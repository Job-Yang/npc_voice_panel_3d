# 自迭代画像 · 铁匠铺欢迎页（场景锚 · profile）

> 本文件是「老杨的铁匠铺」欢迎页这个**实验对象**的自我说明，也是 AutoLoop 每轮宪法的后半段。
> **大方向不可变**——Agent 可在场景内自由发挥，但绝不能把它迭代成一个不相干的东西。

## 这是什么（一句话本质，不可漂移）
「老杨（老羊）的铁匠铺」个人主页的 **3D 欢迎页**。它**永远是一个"欢迎页 / 个人主页门面"**——
有铁匠铺氛围、能体现主人是谁（一个爱用 AI 给自己升级科技的 iOS 工程师、做 iLoop）的可交互展示页。
可以越来越精致、好玩、可探索，但**不是游戏、不是工具、不是别的产品形态**。
隐喻：铁匠铺 = 把混乱的问题锻造成能跑的工具。

## 使用方式 / 怎么跑起来
- **零构建单文件**：几乎所有逻辑在根目录 `index.html`（约 2000 行，清晰中文注释分区）；3D 模型/语音在 `assets/`。
- three.js r0.160 走 CDN importmap，无 npm / 无编译 / 无 CI。
- 本地预览（GLB/wav 需经 http，别用 file://）：`python3 -m http.server 8123`，开 `http://127.0.0.1:8123/`。

## 线上地址（无痕验证用）
https://job-yang.github.io/npc_voice_panel_3d/
- 部署：从 `main` 根目录直发 GitHub Pages，`git push origin main` 即上线（生效约 1–3 分钟）。

## 场景大方向 & 自由度边界
- **默认做减法**：背景铁匠铺 GLB、三个 NPC 与火炉是视觉主体。优先删减、整理、改善构图、灯光、性能、
  可访问性和交互反馈；**禁止用“再加一个可见物件”证明本轮有产出**。
- **资产质量门禁**：不得再用 `BoxGeometry` / `CylinderGeometry` 等基础几何体拼装新的可见家具、机器、
  标牌或装饰。新 3D 资产必须与现有 GLB 的建模、材质和光照质量一致，并且只有替换现有对象、没有净增拥挤度
  时才可采用；拿不准就不加。
- **内容优先同步**：个人主页 `https://jobyang.cn/` 是公开内容事实源。优先从
  `https://jobyang.cn/showcase.json` 更新“老杨是谁、最近在做什么、iLoop/项目”三条角色叙事，
  不在场景里为每篇文章、每个项目新增陈列物。
- **鼓励**：在不增加视觉物件的前提下，优化角色对话、个人页联动、彩蛋、场景灯光、相机、音乐、
  加载性能和可访问性，让画面更克制、更像一个真实入口。
- **红线（本质定位，不可变）**：始终是老杨的**个人主页欢迎页**；铁匠铺主题不可替换；核心要能让访客
  "认识老杨 + 感受手艺人气质 + 找到 iLoop 等项目入口"。不可迭代成与个人主页无关的独立游戏/应用。

## 外部输入的相关性筛选
- 优先关注：优秀个人主页/3D portfolio、空间叙事、可探索交互、three.js/WebGL 能力、可访问性、Web 性能、
  博物馆/展览/游戏环境叙事，以及能强化“铁匠铺手艺人”气质的现实设计。
- 输入不是需求单：外部案例只能提供原则和启发，必须转译成老杨铁匠铺自己的语言、构图与交互，不复制品牌视觉、
  文案、模型或完整交互，也不默认把抽象概念做成新物件。
- 与个人主页认知、铁匠铺叙事、访客探索无关的热点，即使新奇也应拒绝，避免为了追新而堆功能。

## 安全区（放心改，改错也不崩）—— index.html 声明式配置层
- 文案池：`yqLines` / `WELCOME_LINES` / `YQ_EASTER_LINES` / `GUIDE_CARDS`
- 个人页公开摘要：读取 `showcase.json`，更新已有三个 NPC 的文案和链接；网络失败必须保留静态 fallback
- 新增彩蛋：参照 `triggerYQEasterEgg` / `triggerILoopEasterEgg` 的键盘序列框架
- 音乐映射：只替换 `assets/music/` 中的授权音频与场景模式映射，必须验证音量和尾部渐出

## 中风险（可改，但必须视觉/听觉验证）
`SCENE_PRESETS` 灯光与场景模式、相机默认参数（`DEFAULT_CAMERA_*`）、NPC 摆位与角色交互

## 高风险（要改先想清楚，改完必须验证，宁可不改）
- 渲染循环 `animate()`（性能敏感：火焰逐顶点形变、隔帧优化、阴影冻结）
- `loadNPC` 归一化/贴地/骨骼修正（依赖模型内部结构，改错易致 NPC 悬空/入地/姿势诡异）
- BGM 播放、循环与场景切换时序（改错会重叠播放、爆音或无法解除自动播放限制）
- **不要撤销刻意的性能取舍**：`setPixelRatio` 封顶 1.75、`shadowMap.autoUpdate=false`、隔帧顶点更新

## 验证方式
- **本地**：`python3 -m http.server 8123` 打开，确认渲染正常、改动生效、控制台无 error。
- **线上无痕**：push 后等 Pages 生效，用禁缓存/cache-busting（URL 加 `?t=<时间戳>`）或无痕等效方式打开
  线上地址，确认**线上真实效果**（不只信本地），截图存 `.autoloop/journal/assets/<date>.png`。
- 「没弄坏」底线：页面能打开、能拖拽旋转、三个 NPC 与火炉在位、个人页不可用时能回退、无 JS 报错。
- 「值得算一轮」标准：默认相机下，普通访客无需提示，5 秒内能感知本轮主题带来的变化；**删除拥挤物件、
  恢复留白、统一质感、减少干扰同样是完整变化**。变化应帮助访客认识老杨、理解铁匠铺或进入个人页内容。
- 每轮先盘点默认视角中的可见对象数量。除非以同质量资产一换一替换旧对象，否则可见对象数量不得净增加。
- 验收必须分开写：技术验证回答“是否上线且没坏”，体验验证回答“访客是否看得见、看得懂、值得做”。
