# HUMAN FEEDBACK

## 2026-08-25 · 从“每日加东西”改为“持续提高整体质量”

主人反馈：连续多日自迭代都在增加基础几何体拼出的 3D 物件。单个改动看似有功能，但模型质感与原有 GLB
不一致，且小空间被持续占满，最终像杂货铺。

后续必须遵守：

1. 可以新增有价值的 3D 元素，也可以先用简单代理体占位，把摆位、尺度、交互和模型外逻辑做完；但不得把
   基础几何体手搓成“最终模型”，更不能把占位物冒充正式资产。
2. 每轮先检查能否删除、合并或替换已有内容；留白、层级和材质一致性优先于功能数量。
3. 背景铁匠铺 GLB、三个 NPC 与火炉是稳定主体。新资产必须达到同等质量；不强制一换一，但必须证明它值得
   占据有限空间，并通过默认视角的构图验收。
4. 个人主页 `https://jobyang.cn/` 是公开内容事实源。文章、手记和项目更新优先同步到已有 NPC 对话，
   不再为每条新信息造陈列物。
5. 音乐使用专业生成的成品音频，不再使用程序化电子合成器充当最终背景音乐。

评审时先问：这次改动让整体更清楚、更一致了吗？如果只是“多了一个东西”，即使能运行也不算进步。

## 2026-08-25 · 给后续自迭代的方向清单（主人低频批注，优先级高于你自己的想法）

前几轮跑偏的根因不是你不努力，是旧目标逼你“每天必须肉眼可见地多点东西”。对一个已经干净的页面，这
必然变成堆料。现在纠正方向：**你的职责是持续提高这个欢迎页的整体质量，而不是每天往里加东西。**

允许并鼓励的迭代方向（任选其一推进一个完整主题即可，不以新增可见物件为前提）：
1. **内容鲜活**：从 `https://jobyang.cn/showcase.js` 把“最近在做什么 / 项目 / 手记”同步进三个 NPC 的
   对话与链接，让访客每次来都看到老杨的新动态。这是默认最优先方向。
2. **对话与叙事**：打磨 NPC 台词、欢迎语、彩蛋、导览提示，让“认识老杨 + 手艺人气质 + 找到 iLoop 入口”
   这条主线更打动人。文案质量的提升本身就是完整一轮。
3. **视觉与构图收敛**：删冗余、恢复留白、统一材质、调灯光与相机，让画面更克制、更高级。**减法也是进步。**
4. **性能与可访问性**：加载速度、首屏、移动端适配、键盘可达性、降级体验——这些看不见但真实的改善都算数。
5. **氛围**：在不加视觉物件的前提下，优化音乐、火焰、粒子、镜头节奏等沉浸感细节。

硬约束（和上一条批注一起长期生效）：
- **不强求每轮都有视觉增量。** 一轮只要在上述任一方向上做出可验证的改善，就是合格主题；“今天让它更清爽/
  更新/更快/更顺”与“今天加了个东西”同等甚至更值。
- 但**不允许交白卷**：每轮仍要真推进一个主题、留下证据，不能判一句“现状挺好”就躺平。够不到的想法写
  `ASK_HUMAN.md`。
- 仍然默认先问“能删什么、能合并什么、能同步什么”，再考虑“要不要加”；新增元素必须走下面的资产半协作协议。

## 2026-08-25 · 3D 资产半协作协议

AutoLoop 可以提出新增元素，但当前不具备产出同风格高质量 3D 模型的能力。以后按以下方式配合：

1. **AutoLoop 负责定义**：说明元素解决什么体验问题、外观风格、轮廓、材质、颜色、尺寸、摆位、朝向、动画、
   交互、性能预算及建议文件名，并把完整需求写进 `ASK_HUMAN.md`；当天飞书日报必须展示需求摘要和完整链接。
2. **AutoLoop 负责占位和模型外实现**：可以用单个方盒、胶囊体或其他中性代理体表示最终模型的外接轮廓，
   并完成配置、加载接口、摆位、尺度、朝向、交互、碰撞盒、降级逻辑和验收脚本。代理体可以在默认页面显示，
   但必须由独立配置标记为 `asset_pending`，结构简单、颜色克制、替换点唯一，不能继续添加细节把它手搓成模型。
3. **主人负责生成模型**：主人根据需求单提供与现有铁匠铺 GLB 同风格的最终 `.glb` 文件。
4. **AutoLoop 负责替换和收口**：检测到约定文件后接入模型，完成缩放、贴地、灯光、阴影、交互、桌面与移动端
   截图，并确认没有遮挡、材质割裂或把空间重新塞满。
5. **等待期间如实交付**：模型尚未提供时，可以提交并发布“代理体 + 完整模型外逻辑”，本轮写明
   `asset_pending`，飞书向主人展示模型需求。此时可以说“除最终模型外已完成”，不能宣称最终视觉已经完成。
   主人把约定 GLB 放入路径后，AutoLoop 应复用现有配置原位替换，不重新发明一套交互。

不要因为新模型需要主人协作，就机械降低新增方案的评分或回避它。若它确实是三套方案中访客价值最高、最符合
铁匠铺叙事的一套，就选它，主动提需求并把模型外部分推进到 `asset_pending`。
